# Navrang 2026

Single-screen cinematic countdown landing page for Mukand Lal National College, Yamunanagar.

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Assets

- `public/assets/mata-ji.jpg` — primary visual theme
- `public/assets/navrang-2026-poster.jpg` — Navrang branding reference
- `public/assets/dandiya-intro.mp4` — 5-second portrait excerpt of Pixabay's [Dandiya Nights concert crowd video](https://pixabay.com/videos/party-crowd-dancers-dance-lights-236095/), video 236095; free under the [Pixabay Content License](https://pixabay.com/service/license-summary/)
- `public/assets/reference-video.mp4` — supplied UI/animation reference
